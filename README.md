# LHS Modpack

Официальная сборка **Last Human Stronghold** для LHS Launcher.

## Minecraft

- Minecraft: **1.20.1**
- Mod loader: **Forge 47.2.0**

## Структура сборки

Содержимое этого репозитория соответствует структуре `.minecraft` и может содержать:

- `mods/` — моды
- `config/` — конфигурация модов
- `resourcepacks/` — ресурспаки
- `shaderpacks/` — шейдеры
- `defaultconfigs/` — конфигурации для новых миров
- другие необходимые клиентские файлы

## Установка

Игрокам не нужно клонировать этот репозиторий вручную. LHS Launcher получает ZIP последнего релиза из GitHub Releases, распаковывает его в игровую директорию и запускает Minecraft.

## Релизы

Каждая версия сборки публикуется отдельным GitHub Release. В релиз загружается ZIP-архив с корнем, содержащим папки `mods`, `config`, `resourcepacks` и другие файлы сборки.

Пример имени:

`LHS-Modpack-1.0.0.zip`

## Важно

Не добавляйте сюда аккаунты, пароли, токены или другие секреты. Авторизация игроков хранится отдельно в Supabase.
